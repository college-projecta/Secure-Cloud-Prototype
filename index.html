01 / PROCESS

How it works

Plaintext is not the cloud-facing payload in this prototype.

01

Select

Choose a file. It is read as an ArrayBuffer.

02

Encrypt

A random AES-256 key and 96-bit IV are generated for AES-GCM.

03

Segment

Encrypted bytes are divided into configurable blocks.

04

Reconstruct

Blocks are ordered and combined to reproduce ciphertext.

05

Decrypt

AES-GCM authenticates and decrypts the reconstructed data.

04 / SECURITY

What this prototype demonstrates

✓

AES-256-GCM

Authenticated encryption provides confidentiality and integrity checking.

✓

Client-side processing

Encryption and decryption happen in the browser.

✓

Block segmentation

Encrypted bytes are divided only after encryption.

✓

HTTPS + CDN
